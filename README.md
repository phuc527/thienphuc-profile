# Phúc Portfolio

Personal portfolio website inspired by the clean editorial / developer portfolio style of `thanhdat-profile.vercel.app`.

## Stack

- Next.js
- React
- TypeScript
- CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Before deploy

Edit these values in `app/page.tsx`:

- `phucbo755@gmail.com`
- LinkedIn URL
- Experience/company information
- Project descriptions
- Skills if needed

The GitHub avatar is loaded from:

```text
https://github.com/phuc527.png
```

## Deploy to Vercel

Push this folder to a GitHub repository, then import the repository into Vercel.

Build command:

```bash
npm run build
```

Start command:

```bash
npm run start
```
